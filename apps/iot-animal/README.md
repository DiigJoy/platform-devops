# IoT Animal

## Objetivo
Arnes inteligente con sensores y camara para monitorear salud y ubicacion, con app mobile.

## Stack sugerido
- API: NestJS (control y orquestacion)
- IoT: MQTT + WebRTC (stream video)
- Data: MongoDB (estado dispositivo) + S3 (media)
- Mobile: Flutter
- Real-time: WebSockets/Socket.io
